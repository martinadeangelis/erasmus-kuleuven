# 💉 MEMS Microneedles for Closed-Loop Diabetes Management

This repository contains the documentation and research review for a project on Micro-electromechanical Systems (MEMS), focusing on microneedle arrays for continuous glucose monitoring (CGM) and on-demand insulin delivery. 

The project explores the technological evolution of the "artificial pancreas" concept, transitioning from rigid silicon probes to soft, fault-tolerant, and wirelessly integrated closed-loop systems.

## 🔍 Key Research Highlights
The review critically analyzes four distinct microsystem generations:
1.  **Integrated Addressable Arrays (2025):** The core paper, featuring a stainless-steel array with independent channels for redundant sensing and galvanostatically dosed insulin release.
2.  **Hollow Silicon Probes (2018):** A foundational feasibility study of an ultra-miniaturized silicon probe for in-situ interstitial fluid (ISF) sensing, built via classic clean-room micromachining.
3.  **High-Density Silicon Arrays (2022):** A solid array of ~9500 needles/$cm^2$ that uses a ferrocene redox mediator to improve signal strength and selectivity at low potentials.
4.  **Soft Graphene Patch (2016):** An ambitious skin-conformal patch that closed the loop thermally, using bioresorbable microneedles that melt in response to sweat-based glucose readings.

## 🛠️ Manufacturing Trade-offs
A significant portion of the work is dedicated to comparing the fabrication strategies:
*   **Subtractive Clean-room vs. Additive Solution Processing:** Contrasting the high-precision, rigid silicon micromachining (lithography, Bosch DRIE, sputtering) with low-cost, conformal, room-temperature electrochemical deposition.
*   **Reliability & Fault Tolerance:** Analyzing how independent addressing and redundancy protect against single-point sensor failures in vivo.
