# 🚢 Ship Motion Analysis

The project studies the ship's planar motion in 3 degrees of freedom by analyzing the Fossen maneuvering model. 

The main objectives of this work include:
*   Simulating the system's ordinary differential equations (ODEs) starting from a stationary state.
*   Linearizing the maneuvering equations to simulate the system in the state space.
*   Adding time-variant environmental effects, such as ocean currents and wind, to the simulation.
*   Designing a controller based on the nonlinear model to successfully perform a zig-zag maneuver.
